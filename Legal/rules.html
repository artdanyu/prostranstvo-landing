ПРАВИЛА ИСПОЛЬЗОВАНИЯ ПЛАТФОРМЫ «ПРОСТРАНСТВО»

Редакция №1.0

1. Общие положения

1.1. Настоящие Правила определяют порядок использования цифровой AI-платформы «Пространство» (далее «Платформа»).

1.2. Используя Платформу, Пользователь подтверждает, что ознакомился с настоящими Правилами, Публичной офертой, Политикой конфиденциальности и иными опубликованными юридическими документами Платформы.

1.3. Если Пользователь не согласен с настоящими Правилами полностью или частично, он обязан прекратить использование Платформы.

2. Назначение Платформы

2.1. Платформа представляет собой информационный цифровой AI-сервис.

2.2. Платформа предоставляет Пользователю доступ к цифровому функционалу, автоматически формирующему персонализированные информационные материалы.

2.3. Все материалы создаются автоматически с использованием технологий искусственного интеллекта.

2.4. Исполнитель не оказывает консультационных услуг и не осуществляет индивидуальное сопровождение Пользователей.

3. Регистрация и использование

3.1. Для использования отдельных функций Платформы Пользователю может потребоваться регистрация либо авторизация.

3.2. Пользователь обязуется предоставлять достоверные сведения, если их ввод необходим для работы соответствующего AI-модуля.

3.3. Пользователь самостоятельно несет ответственность за сохранность своих устройств, учетных данных и способов авторизации.

4. Использование AI-модулей

4.1. Каждый AI-модуль представляет собой самостоятельную цифровую функцию Платформы.

4.2. Доступность конкретных AI-модулей определяется выбранным Пользователем тарифом либо условиями бесплатного использования.

4.3. Исполнитель вправе изменять состав AI-модулей, их функциональность, интерфейс и внутренние алгоритмы без предварительного уведомления Пользователей.

5. Особенности автоматически формируемых материалов

5.1. Все материалы формируются автоматически без участия Исполнителя.

5.2. Автоматически сформированные материалы носят информационный характер.

5.3. При использовании технологий искусственного интеллекта возможны:

  • различные варианты интерпретации
  • вероятностные выводы
  • неполные ответы
  • неточности
  • ошибки генерации.

5.4. Пользователь принимает во внимание особенности работы технологий искусственного интеллекта при использовании Платформы.

6. Использование материалов

6.1. Материалы предназначены исключительно для личного использования Пользователем.

6.2. Материалы могут использоваться для:

  • самопознания
  • личной рефлексии
  • анализа жизненных ситуаций
  • получения дополнительной информации
  • личного развития.

6.3. Пользователь самостоятельно принимает решения относительно использования полученной информации.

7. Ограничения использования

Пользователю запрещается:

  • использовать Платформу в нарушение законодательства Российской Федерации
  • предпринимать попытки нарушения работы Платформы
  • получать несанкционированный доступ к программному обеспечению, серверам, базам данных либо инфраструктуре Платформы
  • использовать автоматизированные средства (боты, парсеры, скрипты и иные инструменты) для массового обращения к Платформе без письменного разрешения Исполнителя
  • вмешиваться в работу AI-модулей
  • использовать Платформу для распространения вредоносного программного обеспечения
  • использовать Платформу для нарушения прав третьих лиц
  • выдавать автоматически сформированные материалы за официальные заключения специалистов.

8. Интеллектуальная собственность

8.1. Все исключительные права на Платформу, программное обеспечение, дизайн, структуру сервиса, базы данных, тексты, изображения и иные элементы принадлежат Исполнителю либо используются им на законных основаниях.

8.2. Пользователю предоставляется ограниченное неисключительное право использования цифрового функционала исключительно в личных целях.

8.3. Без письменного согласия Исполнителя запрещается:

  • копировать программную часть Платформы
  • модифицировать программное обеспечение
  • распространять элементы Платформы
  • использовать Платформу для создания аналогичных коммерческих сервисов путем копирования ее программной реализации.

9. Техническая доступность

9.1. Исполнитель стремится обеспечивать круглосуточную работу Платформы, однако не гарантирует ее непрерывную доступность.

9.2. Работа Платформы может быть временно ограничена в связи с:

  • техническим обслуживанием
  • обновлением программного обеспечения
  • внедрением новых AI-моделей
  • устранением ошибок
  • обстоятельствами, не зависящими от Исполнителя.

10. Ограничение ответственности

10.1. Исполнитель не несет ответственности за решения, принятые Пользователем на основании автоматически сформированных материалов.

10.2. Исполнитель не отвечает за невозможность использования Платформы вследствие:

  • отсутствия доступа Пользователя к сети Интернет
  • неисправности оборудования Пользователя
  • действий операторов связи
  • действий третьих лиц
  • технических сбоев внешних сервисов
  • обстоятельств непреодолимой силы.

11. Приостановление доступа

11.1. Исполнитель вправе временно ограничить либо прекратить доступ Пользователя к Платформе в случае:

  • нарушения настоящих Правил
  • попыток вмешательства в работу Платформы
  • использования Платформы в противоправных целях
  • угрозы безопасности Платформы либо других Пользователей.

11.2. Приостановление доступа не освобождает Пользователя от обязанностей, возникших до момента такого ограничения.

12. Изменение Правил

12.1. Исполнитель вправе изменять настоящие Правила в любое время.

12.2. Новая редакция вступает в силу с момента ее опубликования на Платформе, если иной срок не указан в соответствующей редакции.

12.3. Продолжение использования Платформы после опубликования новой редакции означает согласие Пользователя с внесенными изменениями.

13. Заключительные положения

13.1. Настоящие Правила применяются совместно с Публичной офертой, Политикой конфиденциальности, Согласием на обработку персональных данных, Политикой возвратов, Тарифами и иными документами Платформы.

13.2. Во всем, что не урегулировано настоящими Правилами, применяется законодательство Российской Федерации и положения Публичной оферты.

13.3. В случае противоречия между настоящими Правилами и Публичной офертой преимущественную силу имеют положения Публичной оферты в части договорных отношений между Исполнителем и Пользователем.
