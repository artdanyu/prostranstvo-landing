2. Персональные данные

Настоящее согласие распространяется на персональные данные, которые Пользователь предоставляет самостоятельно либо которые автоматически формируются в процессе использования Платформы.

К таким данным могут относиться:

  • имя либо псевдоним
  • идентификатор пользователя в Telegram или иной используемой платформе
  • адрес электронной почты (при наличии)
  • сведения, содержащиеся в пользовательских запросах
  • технические данные о работе устройства и соединения
  • IP-адрес
  • сведения о браузере
  • журналы работы сервиса (логи)
  • файлы cookie при использовании веб-версии Платформы
  • иные сведения, добровольно предоставленные Пользователем.

3. Цели обработки

Персональные данные обрабатываются исключительно в целях:

  • предоставления доступа к цифровому функционалу Платформы
  • автоматического формирования персонализированных информационных материалов
  • исполнения Публичной оферты
  • обработки платежей
  • идентификации Пользователя
  • обеспечения безопасности Платформы
  • предотвращения мошенничества и злоупотреблений
  • обработки обращений Пользователя
  • улучшения качества работы Платформы
  • исполнения требований законодательства Российской Федерации.

4. Действия с персональными данными

Оператор вправе осуществлять следующие действия с персональными данными:

  • сбор
  • запись
  • систематизацию
  • накопление
  • хранение
  • уточнение (обновление, изменение)
  • извлечение
  • использование
  • передачу в случаях, предусмотренных настоящим Согласием и законодательством Российской Федерации
  • обезличивание
  • блокирование
  • удаление
  • уничтожение.

Обработка может осуществляться как с использованием средств автоматизации, так и без их использования в случаях, предусмотренных законодательством.

5. Использование технологий искусственного интеллекта

Пользователь подтверждает свое согласие на использование введенных им данных для автоматической обработки посредством технологий искусственного интеллекта исключительно в объеме, необходимом для формирования персонализированных информационных материалов.

Исполнитель не осуществляет индивидуальную ручную обработку каждого пользовательского обращения.

6. Передача персональных данных

Пользователь соглашается, что персональные данные могут передаваться третьим лицам исключительно в случаях, необходимых для функционирования Платформы, включая:

  • обработку платежей
  • предоставление облачной инфраструктуры
  • услуги хостинга
  • обеспечение информационной безопасности
  • исполнение требований законодательства Российской Федерации.
  • Передача осуществляется только в объеме, необходимом для достижения соответствующей цели.

7. Срок действия согласия

Настоящее согласие действует с момента его предоставления до достижения целей обработки персональных данных либо до его отзыва Пользователем, если иное не предусмотрено законодательством Российской Федерации.

8. Отзыв согласия

Пользователь вправе в любое время отозвать настоящее согласие путем направления обращения Оператору по контактным данным, опубликованным в разделе «Реквизиты» Платформы.

Отзыв согласия не влияет на законность обработки персональных данных, осуществленной до момента получения Оператором соответствующего уведомления.

В случаях, когда дальнейшая обработка необходима для исполнения обязанностей, предусмотренных законодательством Российской Федерации, Оператор вправе продолжить обработку в пределах, установленных законом.

9. Подтверждение Пользователя

Предоставляя настоящее согласие, Пользователь подтверждает, что:

  • ознакомился с Политикой конфиденциальности Платформы
  • ознакомился с Публичной офертой
  • ознакомился с Правилами использования Платформы
  • понимает цели обработки своих персональных данных
  • действует добровольно
  • предоставляет достоверные сведения в объеме, необходимом для использования Платформы.
